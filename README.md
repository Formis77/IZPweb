# Modern Web Design Educational Website

A fresh, modern website about web design principles and tools, featuring pastel colors and educational content.

## Features

- **Modern Design**: Clean, responsive layout with contemporary styling
- **Pastel Color Palette**: Soft, eye-friendly colors for a fresh look
- **Educational Content**: Comprehensive guide to web design principles, tools, and examples
- **Interactive Elements**: Smooth scrolling navigation and scroll animations

## Sections

1. **Introduction**: Welcome and overview of web design
2. **Core Principles**: Responsive design, UX, visual hierarchy, accessibility
3. **Essential Tools**: HTML/CSS, JavaScript, design software, frameworks
4. **Design Examples**: Minimalist, Material Design, Dark Mode

## How to View

Simply open `index.html` in your web browser to view the website.

## Technologies Used

- HTML5
- CSS3 (with Flexbox and Grid)
- Vanilla JavaScript
- Google Fonts (Roboto)

## Customization

- Edit `styles.css` to modify colors, fonts, or layout
- Update `index.html` to change content
- Modify `script.js` for additional interactivity
